SCOPE

What is in this review, and what is not

Shown: the top band and the page below it, for the two states that have a layout — signed out, and signed in with orders. The band moves from RotatingHero to PageTopBand, which drops the word that rotates every 2400ms for as long as the page is open, and drops the four invented cycle words that currently describe a tracker this page is not.

Not shown, deliberately rather than by omission:

  • The details card. It is CheckoutIdentityCard, already shipping on /cart/, and it sits between the band and the list. The cart's export server-renders “Loading your cart…”, so the card's markup is not in out/ and cannot be harvested. A hand-pasted copy would be true exactly once, so it is described here instead of drawn wrongly.
  • loading, empty and error. Each is one line of text inside the same band, so a panel of each would show the band four more times and the line once. They are listed in the copy table instead.
  • Hover, focus and the entrance animation. Panels are static by design. The entrance is opt-in in CSS — the settled state is the default — so what is drawn here is what a visitor with no JavaScript, a blocked bundle or a reduced-motion preference sees.
BEFORE

The current page, unmodified

harvested from out/orders/

The band is RotatingHero: an eyebrow badge, “Track your” plus a word that rotates through order / delivery / request / booking every 2400ms, a sub-line, then a section whose only action is a link to /contact/. There is no order data on the page at all.

The rotating pill is clipped on the live page, and the panels reproduce it. The width is measured once on mount, which happens while the fallback font is still in place, and nothing re-measures when Inter arrives. Measured here: 1280px: pill 120px, word needs 132px · 390px: pill 71px, word needs 77px · 280px: pill 62px, word needs 67px · 653px: pill 79px, word needs 86px. The baked width is the pill's live computed width, not the word's, so these frames show the clip rather than a repair. The proposal removes the pill entirely, so the defect goes with it rather than being fixed.

The boxes are the signal, and document.fonts.check('1em Inter') is not: it answered true with the webfont available and true with every request to it aborted, because the API answers for a name it can substitute rather than for the face it actually loaded. A boolean that cannot tell those apart is worse than the measurement, so it is not used as one.

Rows are the same element measured twice, not two different strings — comparing the current h1 against the proposal's would measure the copy rather than the typeface. Both the band and the page's own rungs declare the family rather than inheriting it, so the fallback is the declared stack and not whatever an auth library happens to set on body.
