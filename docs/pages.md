## Running locally

```bash
export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 24
npm run dev     # then open the links below
```

Links point at `http://localhost:3000`. Trailing slashes matter: `trailingSlash` is enabled, so `/terms` redirects and `/terms/` resolves.
