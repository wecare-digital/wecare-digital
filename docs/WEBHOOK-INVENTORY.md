## Razorpay setup, manual

1. Dashboard → **Settings → Webhooks → Add New Webhook**
2. Webhook URL: `https://wecare.digital/api/razorpay-webhook`
3. Secret: must match the `webhook_secret` field in Secrets Manager secret
   `wecare/razorpay-webhook`. If you change one, change both, or signature
   verification fails and every payment webhook is rejected.
4. Select the events listed above.
5. Save, then use **Send Test Webhook** and confirm a 200.

## Razorpay setup, via API
