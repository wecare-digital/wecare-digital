Repair behavior before changing the layout

P2 / CONTRACT

Cancellation has no item route

Client sends DELETE /scheduled/{id}. Live gateway exposes DELETE /scheduled. Scheduled, Templates and cleanup need the same corrected contract.

P2 / CONNECTION

Eight SEO routes use an unconfigured client

The external SEO URL is absent in current Amplify settings. Its separate token is never written by application sign-in. seo-tools editorial workflows are a different backend.

P2 / FEEDBACK

Failed writes can look saved

Welcome and Auto Response ignore updateSystemConfig's false return. Error, retry and unsaved states need to be consistent.

P2 / TRUTHFUL STATUS

Static diagnostics drift from AWS

The Lambda page has 45 static rows and claims two absent functions are active. Billing failure can display a hardcoded $2.40 with a fresh timestamp.

P2 / MISSING WORK QUEUE

New paid requests lack a staff view

Customer service requests use a new table. Current staff tracking reads old Flow submissions. They need linked but distinct queue records.

P2 / EXPERIENCE

Selected channel and missing audio action

Sidebar active-state logic ignores channel query selection. Both inboxes call a transcription route not present on the live gateway.
