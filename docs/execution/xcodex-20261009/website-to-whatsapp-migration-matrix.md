Status: **PARTIALLY COMPLETE**. Classification describes the safe destination architecture; the implementation column states what exists now. It does not declare an undeployed native feature complete.

## Capability preservation and verification

Maintain existing URLs and authenticated web states throughout rollout. Native release requires identity denial cases, pagination, own/foreign selection, action eligibility, private document handling, existing-invoice resend, definitive-failure retry, paid downstream recovery and one owner-observed end-to-end journey. HTTP 200, PUBLISHED Flow, APPROVED template and unit tests are separate evidence layers.

The ₹99/₹350/₹49 amounts above are live Wix variant observations, not hardcoded native prices. Every payable quote must be loaded and frozen server-side. Shipments and review are utility actions unless an explicit business contract establishes otherwise.
