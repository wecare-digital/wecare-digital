# Public hero acceptance follow-up

The 28 registered routes already use Home's RotatingPill or RotatingHero through
their own components; Orders was single-word. Checkout, upcoming pages and
dynamic shop detail were also single-word, and payment status reused the account
access copy. Keep the page-specific identity and use truthful short rotating
words. Upcoming pages remain noindex and explicitly not launched. Do not add
a hero to a redirect-only or private document/error surface.

The shared pill reserves the largest intrinsic word's dimensions using a
single overlapping grid cell. This deliberately trades the former changing
capsule width for stable geometry, preserving rotating word fade, hue and
entrance. The visible pause/resume button is outside the heading; system
reduced motion and hidden tabs stop the timer. Manual pause and system changes
must be tested in each engine.

An isolated Chromium layout fixture exercised 504 word/viewport combinations
across 160–2560 CSS px, including long text: 504 fit with stable height.
This is not the compiled site, actual font/translation, physical foldable,
native WebView or screen-reader evidence. The public acceptance audit PR
#2436 is the full anonymous browser run. Rerun it against the deployed
revision after this change. Authenticated Orders/checkout and payment tests
need approved fixtures. No user transactions are performed.
